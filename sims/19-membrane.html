ねらい

11 の沈降平衡では、粒子は「高さによるエネルギー」と「広がろうとする向き（配置のエントロピー）」のつり合いで、c上/c下 = e−ΔE/kT に分かれました。イオンでは、重力の代わりに電気的なエネルギー zeψ がその役をします（z：価数、e：素電荷）。

膜の内外でイオンが平衡になる条件は、電気化学ポテンシャル μ̃ = μ° + kT ln c + zeψ が内外でそろうこと。そこからネルンストの式 ψin − ψout = (kT/ze) ln(cout/cin) が出ます（教科書 4.9 節）。

やってみよう

  1. Δψ = 0、「K⁺ だけ」で再生。K⁺ は内外で同じ濃度のまま（ln(cin/cout) ≈ 0）。
  2. Δψ を −1 にする（内側が低い電位）。正の K⁺ は内側に集まり、ln(cin/cout) ≈ +1 で止まる。濃度の差で外へ広がろうとする向きと、電位で内へ引かれる向きがつり合う。
  3. いろいろな Δψ で「いまの値を記録」。点は傾き −1 の直線（K⁺ のネルンストの式）に乗る？
  4. 「K⁺ と Cl⁻」にする。負の Cl⁻ は K⁺ と逆に分かれ、傾き +1 の直線に乗る。A⁻ は膜を通れないので、内側にとどまったまま。
  5. 「はじめの状態」を「細胞のように」にし、Δψ = 0 で再生。K⁺ は外へ出ていく（μ̃in > μ̃out）。途中で「K⁺ のネルンスト電位にそろえる」を押すと、正味の移動が止まる。
  6. 「通さない」にすると、濃度差があっても電位差があっても何も起こらない。平衡の条件は「やりとりを許された量」についてだけ成り立つ（12 の仕切りと同じ）。

ネルンストの式の導き方

イオン1個の電気化学ポテンシャルは μ̃ = μ° + kT ln(c/c°) + zeψ。内外で同じ基準をとれば、平衡 μ̃in = μ̃out から 0 = kT ln(cin/cout) + ze(ψin − ψout)。よって cin/cout = e−zeΔψ/kT、すなわち Δψ = (kT/ze) ln(cout/cin)。1 mol あたりで書けば kT → RT、e → ファラデー定数 FA で、教科書の式 (4.16) になる。

平衡でないとき、μ̃in − μ̃out > 0 ならイオンを外へ移すと自由エネルギーが下がるので、正味に外へ出ていく（逆なら入ってくる）。表の「μ̃in − μ̃out」と「外へ出る正味の速さ」の符号がそろうことを確かめよう。

このモデルについて

2次元剛体円板気体（m = 1、k = 1）。膜を越えるとき、イオンは電気的なエネルギーの差 zeΔψ の分だけ膜に垂直な速さを変える（足りなければ跳ね返る）。11 の段差と同じしくみで、運動＋電気的なエネルギーは厳密に保存される。まわりの壁は温度 1 の環境と熱をやりとりするので、温度はほぼ一定。

この模型では、イオンどうしの電気的な力（クーロン力）は入れず、膜電位 Δψ は外から与えた値として扱う（電位を固定した実験に当たる）。実際の細胞では、膜電位は膜の両側にたまったごくわずかな電荷の差でつくられ、それは濃度にくらべて無視できるほど小さい。
