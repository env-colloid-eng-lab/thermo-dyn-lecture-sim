ねらい

外側を断熱・固定にした孤立系を、仕切りで二室に分ける。仕切りが何のやりとりを許すかで、平衡でそろう量が決まる。どの場合も、許された変化は全体のエントロピーを増やす向きに進み、増える余地がなくなったところが平衡（第二法則）。

  • 透熱・固定（エネルギーだけ）→ T₁ = T₂
  • 透熱・可動（エネルギーと体積）→ T₁ = T₂ かつ P₁ = P₂
  • 粒子を通す（エネルギーと粒子）→ T₁ = T₂ かつ μ₁ = μ₂

やってみよう

  1. 「断熱・固定」のまま待つ。どの係数も 0 でないのに何も変わらない。仕切りがすべてのやりとりを禁じている（拘束）。
  2. 「透熱・固定」にする。温度の係数だけが 0 に向かい、T₁ = T₂ になる。圧力はそろう？（N₁ ≠ N₂ なので、固定壁が圧力の差を支えている）
  3. 「透熱・可動」にする。壁が動き、温度に加えて圧力もそろう。壁はどこで止まる？（V₁/V₂ = N₁/N₂）
  4. 「粒子を通す」にする。粒子が行き来して、温度と数密度（化学ポテンシャル）がそろう。
  5. どの場合も「全体の ΔS」は増えてから一定になる。
問い　透熱・固定の壁で平衡になったとき、P₁ = P₂ まで結論してよいだろうか？ 壁を動けるようにすると、式のどの項が新たに残るか。
問い　左右で濃度が違っても、粒子を通さない壁なら濃度差は解消されない。「濃度差があれば必ず移動する」と言ってよいだろうか？ 平衡を述べるときは、何のやりとりを許した平衡かまで指定しよう。
問い　（参考）断熱・可動の壁では、圧力はすぐにそろうが温度はなかなかそろわない。エネルギーを熱として通さない壁でも、壁が動くと左右でエネルギーが移るのはなぜ？
係数の求め方（2次元理想気体）

各室のエントロピーは S = Nk[ln(V/N) + ln T] + N·定数。孤立系では dU₂ = −dU₁、dV₂ = −dV₁、dN₂ = −dN₁ なので、dS = dS₁ + dS₂ を書くと上の式になる（∂S/∂U = 1/T、∂S/∂V = P/T、∂S/∂N = −μ/T）。

仕切りが禁じる変化は 0 とし、許す独立な変化の係数を 0 とおくと平衡条件が得られる。2次元理想気体では P/T = n、μ/T = ln(n/T) + 定数 なので、温度がそろった後は、圧力の条件も粒子の条件も「数密度がそろう」になる。

図の全体の ΔS は、左右の気体と透熱壁（熱容量 Cw）の和 N₁ ln(V₁T₁/N₁) + N₂ ln(V₂T₂/N₂) + Cw ln Tw の、はじめからの変化。

モデルについて

可動の仕切りは質量 M の壁で、粒子との衝突で運動量をやりとりする。透熱なら、壁と一緒に動く座標系で壁の温度のマクスウェル分布に従って粒子を跳ね返す。気体・壁の内部エネルギー・壁の運動エネルギーの和は厳密に保存する。壁自身も熱運動するので、平衡でも少しゆれ続ける。

「粒子を通す」壁はすべての粒子を素通りさせる（色は、はじめどちらにいたかの目印）。同じ種類の気体なので、混ざっても混合のエントロピーは生じない（07 の「区別しない」と同じ）。
