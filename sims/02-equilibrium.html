ねらい

温度の違う二つの流体を 透熱壁 で接触させて放置すると、やがてマクロな変化のない状態（平衡状態）に落ち着く。講義の「コーヒーと部屋」の例をミクロに見ます。

エネルギー保存だけでは、エネルギーが 1→2 と 2→1 のどちらへ移るかは決まらない。向きを決めるのは 第二法則（エントロピー原理）：孤立した複合系の内部の拘束（ここでは断熱壁）を外すと、全体のエントロピー S₁ + S₂ が増える向きに変化が進み、最大になったところが平衡状態になる。

やってみよう

  1. 断熱壁のまま待つ。T₁, T₂ は変わる？　S(U₁) の図の黒い点は動く？（断熱壁はエネルギーのやりとりを禁じる「拘束」）
  2. 「透熱壁」に替える。どちらからどちらへエネルギーが移る？　壁のところで粒子の速さはどう変わる？（「色＝速さ」が見やすい）
  3. 黒い点が S(U₁) の曲線をのぼっていくことを確かめる。点はどこで止まる？　そこで 1/T₁ と 1/T₂ はどうなっている？
  4. 十分に待つ。T₁ と T₂ はどうなる？　U₁ と U₂ は等しくなる？（N₁ ≠ N₂ にして試す。曲線の頂上の位置も変わる）
  5. 平衡に達したあとも粒子は動き続けている。グラフの細かい揺らぎは何？
  6. 最後に「取り除く」。二つの流体が混ざる。ここから元の状態に戻るまで待つことはできる？
問い　平衡状態では T₁ = T₂ になりましたが、U₁ = U₂ とは限りません。平衡で等しくなるのは「示強変数」と「示量変数」のどちら？（→ 05 で確かめる）
問い　粒子数を 40 個まで減らすと揺らぎはどうなる？　熱力学が「マクロな物質」を対象にするのはなぜ？
問い　S(U) の傾き 1/T が大きいのは、高温側と低温側のどちら？　傾きが大きい側にエネルギーを渡すと全体の S が増えることから、「熱は高温側から低温側へ流れる」を説明してみよう。
エントロピーの曲線（2次元理想気体）

体積と粒子数が一定の 2次元理想気体では S = Nk ln U + （V, N だけで決まる定数）。U で微分すると ∂S/∂U = Nk/U = 1/T（U = NkT）。この「エントロピーの傾きが 1/T」を熱力学的な温度の定義として使う。

全体のエントロピーを U₁ で微分すると dS/dU₁ = 1/T₁ − 1/T₂。T₁ > T₂ なら負なので、U₁ が減る向き（1 から 2 へエネルギーが移る向き）に S が増える。頂上 dS/dU₁ = 0 が T₁ = T₂。曲線は上に凸（凹関数）なので、頂上はただ一つで、そこが安定な平衡になる。

図の ΔS は、はじめの状態からの変化 ΔS = N₁ ln(U₁/U₁⁰) + N₂ ln(U₂/U₂⁰)（k = 1）。曲線は、いまの気体のエネルギーの合計 U₁ + U₂ で描いています（仕切り壁が一時的に蓄える分だけ、この合計はわずかに変わる）。透熱の仕切り壁も小さな熱容量 Cw をもつので、「全体の ΔS」には壁の分 Cw ln(Tw/Tw⁰) も含めています（気体・壁を合わせた孤立系のエントロピー）。粒子数が有限なので、点は平衡のまわりで少しゆらぎます。

モデルについて

透熱壁は「小さな熱容量をもつ壁」として模型化しています。粒子が壁に当たると、壁の温度 Tw のマクスウェル分布に従う速度で跳ね返り、そのぶん壁のエネルギーが増減します。両側の粒子が同じ壁とエネルギーをやりとりするので、壁を通して左右の流体の間で熱が移動します（気体＋壁の全エネルギーは厳密に保存）。
