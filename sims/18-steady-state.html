ねらい

02 や 11 では、放っておくと気体は平衡に落ち着き、そこで変化が止まりました。平衡では全体のエントロピーが最大で、熱も物質も正味には流れません。

では、下を熱い熱源、上を冷たい熱源にはさんだらどうなるか。しばらくすると気体の温度の分布は変わらなくなります。でもそれは平衡ではありません。熱が熱い方から冷たい方へ流れ続け、全体のエントロピーは増え続けます。これを定常状態（非平衡定常状態）といいます。地球の気候（15・17）も、生き物の細胞も、この「流れに支えられた定常状態」です。

やってみよう

  1. はじめは上下とも T = 1（同じ温度）。Q̇h も −Q̇c も 0 のまわりでゆらぐだけで、温度は高さによらず一様。これが平衡。
  2. 「温度差をつける」を押す（Th = 2、Tc = 0.5）。しばらくすると温度は下ほど高い分布で止まり、dU/dt ≈ 0 になる。それでも Q̇h ≈ −Q̇c > 0：入った熱と同じだけ出ていく。
  3. 下のグラフで、熱源のエントロピーの合計が一定の速さで増え続けることを確かめる。気体の状態は変わらないのに、全体ではエントロピーが作られ続けている。
  4. 「混み具合」のグラフ：冷たい上の方ほど粒子が混んでいる。圧力（上下でほぼ同じ）をそろえるには、温度が低いところほど多くの粒子が必要。
  5. 「熱源を外す」を押す。熱の流れが止まり、温度の分布はならされて一様になる（平衡へ戻る）。定常状態は、外から熱を流し続けないと保てない。
  6. 温度差を半分にすると Q̇ と σ はどう変わる？（σ はおよそ温度差の2乗に比例する）
問い　定常状態でも平衡でも「気体の状態は時間によらない」。では二つの違いは何？　熱の流れとエントロピーの生成、外から何を供給しているかで答えよう。
問い　熱い熱源から入った熱 Q がそのまま冷たい熱源へ出ていくとき、全体のエントロピーの変化 ΔS = −Q/Th + Q/Tc の符号は？　熱が冷たい方から熱い方へひとりでに流れる定常状態がないのはなぜ？
問い　地球は太陽（約 5800 K）から放射を受け取り、宇宙（約 3 K）へ放射を出して、ほぼ定常状態にある。細胞は ATP を作り続けて、平衡から離れた状態を保っている（4.10 節）。どちらも、このページの気体と何が同じか？
エネルギーとエントロピーの帳簿

第一法則：dU/dt = Q̇h + Q̇c（ピストンは止めてあるので W = 0）。定常状態では dU/dt = 0 なので Q̇h = −Q̇c ≡ Q̇。

熱源のエントロピーの変化は、熱源が受け取った熱をその温度で割ったもの：dS熱源/dt = −Q̇h/Th − Q̇c/Tc。全体のエントロピーを作る速さは、これに気体のエントロピーの変化を足した σ = dS熱源/dt + dS気体/dt。定常状態では気体のエントロピーは変わらないので σ = Q̇ (1/Tc − 1/Th) ≥ 0。熱が熱い方から冷たい方へ流れる（Q̇ > 0、Th > Tc）ときだけ正になる。これは第二法則が決める流れの向き。

気体の項を落とすと困るのは平衡のとき。上下が同じ温度 T でも、気体のエネルギーは熱のやりとりでゆらぎ（dU/dt ≠ 0）、熱源の項 −dU/(T dt) は 0 のまわりでゆれる。気体の項 dU/(T dt) がちょうどそれを打ち消すので、σ ≈ 0 になる（エネルギーが行き来しているだけで、エントロピーは作られていない）。このページでは気体の項を dU/T で近似している（気体の中に温度の差があるときは近似）。

温度差が小さいとき、熱の速さは温度差に比例する（フーリエの法則 Q̇ ∝ Th − Tc）。すると σ は温度差の2乗に比例する。

平衡と定常状態の違い（教科書 8.7 節）

沈降平衡（11）は、外から何も供給しなくても続く平衡で、全体のエントロピーは最大、正味の流れはない。気候の放射対流平衡（17）は、名前に「平衡」とついているが、太陽からのエネルギーが入って宇宙へ出ていく流れに支えられた定常状態で、エントロピーを作り続けている。このページの気体は後者のいちばん簡単な例。

このモデルについて

2次元剛体円板気体（m = 1、k = 1、U = NkT）。他のページより粒子を大きくして（半径 1）、熱が粒子どうしの衝突でリレーされるようにしている。粒子が熱源の壁に当たると、その熱源の温度の分布から速さを選び直して跳ね返る（ミクロに見た熱のやりとり）。帳簿は衝突1回ごとのエネルギー変化をすべて足したもので、ΔU = Q + W が厳密に成り立つ。

壁のすぐそばの層の温度は熱源の温度と少しずれる（壁で温度がとぶ）。粒子が壁に当たる回数が有限で、壁との熱のやりとりが完全ではないため。粒子が多い（気体が濃い）ほど、とびは小さくなる。粒子に大きさがあるので、状態方程式は理想気体から少しずれる（混み具合と温度の積は高さで少し変わる）。
