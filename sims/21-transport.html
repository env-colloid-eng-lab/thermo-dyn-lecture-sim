ねらい

11 では、沈降平衡の分布 c(z) ∝ e−mbgz/kT を自由エネルギー最小から求めました。熱力学が教えるのは行き先（平衡の分布）です。でも、そこへどれだけ速く着くかは教えてくれません。速さは拡散係数 D や移動度 b（粘度で決まる）による、熱力学とは別の情報です（教科書 4.5 節）。

ただし、D と b は勝手に決めてよいわけではありません。流れが止まる分布が平衡の分布と一致するには D = bkT（アインシュタインの関係）が必要です。

やってみよう

  1. 再生する。左右とも、一様な分布から底に濃い指数関数の分布へ近づく。行き先（破線）は同じだが、粘度が k 倍の右は k 倍ゆっくり近づく。
  2. 自由エネルギーの差のグラフ：どちらも減り続け、0（平衡）で止まる。増えることはない（第二法則）。
  3. 流れの内訳：はじめは重力による下向きの流れが勝つ。分布が偏ると拡散の上向きの流れが育ち、平衡では各高さでぴったり打ち消す。粒子は動き続けているのに、正味の流れは 0。
  4. 「上の方に集める」から始める。はじめの状態が違っても、行き先は同じ。
  5. P を変える。P が大きい（重い・容器が高い）ほど底に集まり、早く平衡に近づく。P < 0 は浮く粒子。
  6. r を 1 からずらす（アインシュタインの関係を破る）。流れが止まる分布が e−Px/r になり、ボルツマン分布からずれる。自由エネルギーの差も 0 にならない。
問い　平衡の濃度の式 dc/dz = −mbg c/kT を流れの式 J = −D dc/dz − b mbg c に入れて、J = 0 になる条件を求めよう（教科書の途中の問い 4.2）。
問い　例題4の粒子で P = 5（容器の高さ 80 µm）のとき、H²/D は約 4 時間。顕微鏡で沈降平衡を観察するとき、何に気をつける？　粒子の直径が半分なら？
問い　粘度を上げても平衡の分布が変わらないのはなぜ？　「どこに着くか」と「どれだけ速く着くか」を決めるものを、それぞれ言葉で説明しよう。
流れの式と時間の目安

上向きを正とした粒子の流れは、拡散（フィックの法則）と重力による移動の和 J = −D ∂c/∂z − b mbg c（式 4.6）。薄い層への出入りから ∂c/∂t = −∂J/∂z（式 4.8）。x = z/H、τ = tD/H² とすると ∂c/∂τ = ∂²c/∂x² + (P/r) ∂c/∂x、P = mbgH/kT、r = D/(bkT)。

時間の目安は、拡散で高さ H を広がる tD ~ H²/D（τ = 1）と、沈む速さで H を進む tg = H/(b mb g)（τ = r/P）。平衡へ近づく正確な時間ではなく目安。

ストークスの抵抗 b = 1/(6πηa) から D = kT/(6πηa)。粘度 η を k 倍にすると D と b がどちらも 1/k になり、行き先は同じで時間だけが k 倍になる。

このモデルについて

このページは粒子どうしの衝突（分子動力学）ではなく、ブラウン運動の模型です。水の分子は描かず、その効果をでたらめな押し（拡散）と抵抗（移動度）で表します。粒子1個の高さは 1 刻みごとに Δx = −(P/r) Δτ + √(2Δτ) ξ（ξ は平均 0、分散 1 の乱数）で動き、底と上で跳ね返ります。横方向の動きは見た目のためだけです。

線は同じ式 (4.8) を、高さを 120 層に分けて解いたもの（教科書の付属プログラム sedimentation.py と同じ解き方：平衡を厳密に保つ流れの書き方と、陰解法）。P = 5 で付属プログラムの結果と 6 桁まで一致することをテストで確かめています。実際の長さ・時間（3次元・SI 単位）は例題4の粒子で換算しています。
