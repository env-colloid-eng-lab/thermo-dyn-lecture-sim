ねらい

温度 T の理想気体の体積を 2 倍にする。A は熱源に接したままピストンをゆっくり引く（可逆な等温膨張）。B は断熱容器の仕切りを外して真空へ広がらせる（自由膨張）。どちらも終わりは「温度 T、体積 2 倍」の同じ平衡状態で、ΔU = 0。

それでも熱 Q と仕事 W は経路によって違う（状態量ではない）。一方、気体のエントロピー変化は同じ。違いは 外界（熱源）のエントロピー に現れ、全体のエントロピー変化は A で 0、B で Nk ln 2。第二法則 ΔS_全体 ≥ 0 から、取り出せる仕事には上限 W_out ≤ −ΔF（最大仕事の原理）がつく。

やってみよう

  1. 「膨張を始める」。B はすぐに広がるが、A はピストンがゆっくり動く（再生速度を上げてよい）。表の Q, W, ΔU を A と B で比べる。
  2. 終わったら「気体の ΔS」と「熱源の ΔS」を比べる。A では熱源から受け取った熱のぶん熱源の S が減り、全体ではほぼ 0。B では熱源とやりとりがなく、全体で N ln 2 増える。
  3. 下の棒グラフ：A は上限 −ΔF いっぱいまで仕事を取り出し、B は 0。B では取り出せたはずの仕事 NkT ln 2 がすべて「失われた」。
  4. 「速い」にして、もう一度。A の取り出した仕事は減り、そのぶん全体のエントロピーが増える（失われた仕事 TΔS_全体）。合計はいつも −ΔF の近く。
問い　B の気体を、ひとりでに左半分へ戻らせることはできない。第二法則でどう説明できる？ 外から仕事をして元に戻すとき、最低どれだけの仕事が必要か（最小仕事 W ≥ ΔF）。そのとき熱源へ出ていく熱は？
問い　自由膨張でもエネルギーは少しも減っていない（ΔU = 0）。それなのに「仕事を取り出す機会が失われた」とはどういう意味だろう？
問い　A でもゆっくりなら全体の ΔS ≈ 0。では A を逆向き（ゆっくり圧縮）に行うと、気体・熱源・外界はすべて元に戻るだろうか？ B を逆向きにできないこととの違いは？
理論値（2次元理想気体, k = 1）

可逆な等温膨張：W = −∫P dV = −NkT ln(V₂/V₁) = −NkT ln 2、Q = −W。気体の ΔS = Nk ln 2、熱源の ΔS = −Q/T = −Nk ln 2、全体で 0。

自由膨張：Q = W = 0、ΔU = 0 なので温度は変わらず、終状態は可逆な等温膨張と同じ。気体の ΔS = Nk ln 2（状態量）、熱源の変化はないので全体で Nk ln 2。

ヘルムホルツの自由エネルギー F = U − TS の変化は、どちらも ΔF = −NkT ln 2。熱源（温度 T）と熱をやりとりする過程では Q ≤ TΔS（第二法則）なので、第一法則と合わせて W ≥ ΔF、取り出す仕事 W_out = −W ≤ −ΔF。さらに W_out = −ΔF − TΔS_全体 と書け、不可逆性（ΔS_全体 > 0）があると取り出せる仕事が減る。

測定値について

粒子は大きさのある円板なので、圧力は理想気体より少し大きく、A の |W| は理論値より 2〜3％大きくなります。そのため A をゆっくり動かしても、全体の ΔS は 0 のまわりに数程度（N ln 2 ≈ 139 に比べて小さい）ずれることがあります。粒子数が少ないので、気体の温度と熱源の ΔS はゆらぎますが、両者のゆらぎは打ち消し合うので、全体の ΔS はなめらかです。
