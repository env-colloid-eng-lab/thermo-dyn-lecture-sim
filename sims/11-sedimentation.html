ねらい

同じ大きさの二つの領域で、上の領域にいる粒子だけエネルギーが ΔE 高いとする（重力のある容器の上と下）。粒子はどう分かれるだろう？

  • 場合の数（配置のエントロピー）だけを考えると、半分ずつが最も多い。
  • エネルギーだけを考えると、全部が下にいるのが最も低い。

実際はその間に落ち着く。熱源（温度 T）に接触していれば、決め手は 自由エネルギー F = U − TS の最小で、上にいる割合 x は x/(1−x) = e−ΔE/kT。これは「系＋熱源」全体のエントロピー最大（第二法則）を、系の量だけで言い直したもの。孤立系なら、全体のエントロピーが最大になる所で止まる。層を細かくすると、重力の下での 沈降平衡 c(z) ∝ e−z/ℓ（ℓ = kT/mg：重力長）になる。

やってみよう

  1. 「二領域」「熱源に接触」で再生する。x は 1/2 から減り、理論値のまわりでゆらぐ。F(x) の図の黒い点は谷底へ向かう。
  2. ΔE を 0 にすると？ 大きくすると？ 熱源の温度 T を上げると？（x は ΔE/kT だけで決まる）。ΔE < 0 にすると上の方が低エネルギー（水に浮く粒子）。
  3. 「エントロピーの収支」を見る。粒子が下に集まるので系の配置のエントロピーは減る。それでも熱源へ熱が出ていくぶん熱源のエントロピーが増え、全体では増える。
  4. 「断熱（孤立系）」にする。粒子が下へ移ると位置エネルギーが運動エネルギーになり、気体の温度が上がる（「色＝速さ」）。今度は全体のエントロピー S(x) が最大の所で止まる。
  5. 「多段（重力の近似）」にして層の数 n を増やす。層ごとの濃度が、なめらかな指数関数 e−z/ℓ に近づく。mgH や T を変えると？
  6. 「二状態」にする。上の領域はエネルギーが ΔE 高いが、広さが v₂（下は v₁ = 1 − v₂）なので置き方が多い。熱源の温度を上げていくと、x = 1/2 をまたいで上の領域が優勢になる。その温度 Tm を下のグラフで確かめよう（タンパク質の変性・融解のモデル）。
  7. 途中で ΔE を変えると、帳簿の W が変わる。段差を変えることは、粒子を持ち上げる（下ろす）外からの仕事。
問い　平衡でも粒子は上下を行き来し続けている。「平衡では移動が止まる」のではないとしたら、何がつり合っているのだろう？（上へ越える数と下へ来る数を考えよう）
問い　ΔE = 2kT のとき x はいくら？ 計算してからシミュレーションで確かめよう。高い方の領域も空にはならないのはなぜ？
問い　熱源に接触しているとき、系のエントロピーは減っているのに変化がひとりでに進む。第二法則と矛盾しないのはなぜ？ ΔS_全体 = −ΔF/T を示してみよう（ヒント：W = 0 なら ΔU = Q）。

二領域の自由エネルギー

N 個の粒子のうち Nx 個が上にいる配置の数は W = N!/((Nx)!(N−Nx)!)。スターリングの近似で S_conf = −Nk[x ln x + (1−x) ln(1−x)]。速さの分布の部分は温度 T 一定なら x によらないので、

F/N = xΔE + kT[x ln x + (1−x) ln(1−x)] + 定数

x で微分して 0 とおくと ΔE + kT ln(x/(1−x)) = 0、つまり x = 1/(1 + eΔE/kT)。二階微分は正なので最小。図の F は 1粒子あたりで、x = 1/2 の値からの差を描いています。

孤立系では全エネルギー E が一定。2次元なので運動エネルギー = NkT から、上へ x の割合を上げると T = E/N − xΔE に下がる。全体のエントロピー S/N = −k[x ln x + (1−x) ln(1−x)] + k ln T の最大も、終わりの温度で同じ式 x/(1−x) = e−ΔE/kT を満たす。

多段と沈降平衡（重力長）

容器を n 層に分け、下から k 番目の層の粒子1個のエネルギーを k·mgH/n とする（重力の位置エネルギー mgz を階段で近似）。どの隣り合う2層の間でも二領域と同じ条件が成り立つので、割合は e−k·mgH/(nkT) に比例する。n を大きくすると連続な分布 c(z) = c(0) e−z/ℓ、ℓ = kT/mg になる。図の点線は連続な重力の場合です。

平衡で一定になるのは濃度ではなく、濃度の項と位置エネルギーの項を合わせた化学ポテンシャル kT ln c(z) + mgz。等温大気の圧力（密度）が高さとともに指数関数で減るのも同じ式です。

二状態モデル（タンパク質の折りたたみ）

上の領域に置ける場所の数は下の v₂/v₁ 倍なので、粒子1個あたりのエントロピーが Δs = k ln(v₂/v₁) だけ大きい。上下の自由エネルギー差は Δg = ΔE − TΔs になり、x/(1−x) = e−Δg/kT = (v₂/v₁)e−ΔE/kT。

低温では ΔE の項が勝って下（エネルギーが低い状態）が優勢、高温では TΔs の項が勝って上（置き方の多い状態）が優勢。入れ替わる温度は Δg = 0 から Tm = ΔE/Δs。タンパク質では、下＝折りたたまれた状態 F（分子内の結合でエネルギーが低いが、形は限られる）、上＝ほどけた状態 U（エネルギーは高いが、とれる形が多い）にあたり、Δh − TΔs の符号が変わる温度で変性する。

エントロピーの収支の数え方

系の配置のエントロピーは層への分け方の数 ln(N!/ΠN_k!)（層の大きさは同じ）。速さの部分は2次元の理想気体で Nk ln T。熱源のエントロピー変化は、受け取った熱を熱源の温度で割ったもの（気体が受け取った熱 Q の符号を反転）。表示の温度は少しならした値です。粒子数が少ないので、どの量もゆらぎます。

モデルについて

段差の境目に来た粒子は、鉛直方向の運動エネルギーが段差 ΔE より大きければ、そのぶん鉛直の速さを落として上の層へ進み、足りなければ跳ね返る（下りるときは速くなる）。位置エネルギーは層の番号だけで決まるので、運動エネルギーと位置エネルギーの和は厳密に保存します。境目は壁ではなく、エネルギーの段差です。

粒子は大きさのある円板なので、粒子が混み合う下の層では理想気体より少し「窮屈」になり、上にいる割合は理論値よりわずかに（1％程度）大きくなります。
