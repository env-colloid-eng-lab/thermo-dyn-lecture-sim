ねらい

長さ b の節を Ns 本、向きをでたらめに選んでつないだ鎖（理想鎖）。どの形もエネルギーは同じなのに、末端を引き離して保つには力がいる。理由は 配置の数：末端が原点の近くにある形はたくさんあるが、遠くにある形は少ない。伸ばすとエントロピーが減るので、温度 T の環境の中では自由エネルギー F = U − TS が増える。その傾きが力 f = dF/dx。

手を離すと鎖は縮む。縮む向きに配置の数（エントロピー）が増えるから ― 変化の向きを決めているのは、ここでも第二法則。

やってみよう

  1. 再生して、鎖をたくさんつくる。末端（灰色の点）は原点のまわりに集まり、遠くほど少ない。上のグラフの分布はガウス分布に近づく。
  2. 「伸ばした長さ」を変える。帯の中に末端が入る割合 P(x) は、x = 0 に比べてどれだけ少ない？ それが配置のエントロピーの減少 ΔS = k ln(P(x)/P(0))。
  3. 下のグラフの F(x) は放物線。傾き（接線）が必要な力で、x に比例する（フックの法則）。ばねと同じ形だが、起源はエネルギーではなくエントロピー。
  4. 温度を2倍にすると力は？（分布は変わらないのに、力は T に比例する）
  5. 節の数 Ns を増やすと、同じ x での力は？（長い鎖ほど柔らかい）
問い　輪ゴムに重りをつるして、ドライヤーで温めるとどうなる？ ふつうの金属のばねと逆になるのはなぜ？（f ∝ T）
問い　輪ゴムをすばやく伸ばして唇に当てると温かい。断熱的に伸ばすと、配置のエントロピーの減少を何が補っている？（全体のエントロピーは減らない）
問い　ゆっくり伸ばすとき、した仕事 W = ΔF はどこへ行く？ 理想鎖では ΔU = 0 であることと、第一法則から考えよう。
理論（2次元の理想鎖）

末端の x 座標は x = Σ b cos θj。各項は独立で平均 0、⟨cos²θ⟩ = 1/2 なので σ² = ⟨x²⟩ = Nsb²/2（3次元なら Nsb²/3）。多数の独立な寄与の和なので、分布はガウス分布 P(x) ∝ e−x²/2σ² で近似できる（中心極限定理）。

同じ幅の帯に末端が入る配置の数の比は P(x)/P(0) なので、S(x) − S(0) = k ln(P(x)/P(0)) = −kx²/2σ²。理想鎖ではエネルギーが形によらないので F(x) − F(0) = −T(S(x) − S(0)) = kTx²/2σ²。最小仕事の等号 δW = dF から、外から加える力は f = dF/dx = kTx/σ² = 2kTx/(Nsb²)（3次元なら 3kTx/(Nsb²)）。

ガウス近似は、末端間の距離が鎖の全長 Nsb より十分短い範囲で使える。この教材では長さ b = 1、k = 1。
