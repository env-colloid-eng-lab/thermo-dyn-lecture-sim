操作パネル

条件

はじめの気体の温度は T = 1。熱源の温度を 1 より低くすると「冷やす」実験になります。条件を変えたら「はじめから」。

表示

ねらい

物体の温度を 1 だけ上げるのに必要な熱を 熱容量 C = Q/ΔT という。同じ気体でも、体積を一定にして温めるか、圧力を一定にして温めるかで値が違う。その理由を、ピストンがする仕事から考える。

やってみよう

  1. 「定積」で測定。表の C/N はいくつ？ 熱源の温度を変えて何回か測り、グラフの点がどの直線に乗るか見る。
  2. N を変えて測る。C は N に比例する（示量変数）が、C/N は変わらない。
  3. 「定圧」に切り替えて測定。ピストンが外へ動き、気体が外へ仕事をする（W < 0）。C/N はいくつになる？
  4. 熱源の温度を 1 より低くして「冷やす」測定もしてみよう（Q < 0, ΔT < 0）。
問い　定圧で温めると、定積のときより多くの熱が必要になる。余分な熱はどこへ行った？ 第一法則 ΔU = Q + W で説明してみよう。
問い　熱源の温度まで上がりきる前に熱源から離しても、C は正しく求まる。なぜ？
問い　同じ測定を何回か繰り返すと、C/N は少しずつばらつく（特に定圧で N が小さいとき）。何がゆらいでいるのだろう？
理論値（2次元単原子理想気体）

U = NkT なので、定積では Q = ΔU、CV = Nk（C/N = 1）。

定圧では気体が外へ仕事 PΔV = NkΔT をするので Q = ΔU + PΔV、CP = 2Nk（C/N = 2）。CP − CV = Nk（マイヤーの関係）、γ = CP/CV = 2。

3次元の単原子理想気体なら CV = (3/2)Nk、CP = (5/2)Nk。違いは1粒子あたりの自由度の数（2次元は 2、3次元は 3）。

このシミュレーションでは温度を T = U/N で決めているので、定積の C/N はちょうど 1 になります。定圧ではピストンのゆらぎ（気体とおもりの間のエネルギーのやりとり）のため数％ばらつきます。定圧で冷やすと体積が小さくなり、粒子の大きさの効果（理想気体からのずれ）で C/N が 2 より少し小さく出ます。
