ねらい

断熱容器の中でひとりでに起こる変化（自由膨張・混合・熱の移動）は、逆向きにはひとりでに起こらない。この「一方向性」を表す状態量が エントロピー S。孤立した系では ΔS ≥ 0（熱力学第二法則）。

やってみよう

  1. 「自由膨張」で仕切りを外す。粒子は右へ広がり、左に戻ってこない。ln W は理論の ΔS = N ln 2 の近くで落ち着く。
  2. N = 4 や 10 にして同じことをする。全部が左に戻る瞬間が見えるかも。N が大きいと？（右下の「確率」を見る）
  3. 仕切りを外してすぐに「速度を反転」すると、粒子は左に戻っていく。しばらく待ってから反転すると？（下の「速度を反転しても戻らないのは？」も読もう）
  4. 「混合」：A と B が混ざって戻らない。「区別しない」にすると、同じ気体どうしの「混合」では ΔS ≈ 0。
  5. 「熱の移動」：温度の違う2つの気体を透熱壁で接触させる。熱は高温側から低温側へ流れ、全体の S は増える。
問い　粒子どうしの衝突も壁での反射も、時間を逆にしても成り立つ力学の法則に従っている。それなのに、なぜ「元に戻る」変化はひとりでには見られないのだろう？（「全部の粒子の速度をちょうど逆にする」ような状態がどれくらい特別か、場合の数で考えよう）
問い　「熱の移動」で、低温側が受け取る熱 Q₂ と高温側が失う熱 −Q₁ はほぼ同じ大きさ。それなのに全体のエントロピー Q₂/T₂ + Q₁/T₁ が正になるのはなぜ？
エントロピーの数え方（ボルツマンの式）

容器を左右半分に分け、「左に n 個」というマクロな状態に対応する粒子の分け方の数を W = C(N, n) = N!/(n!(N−n)!) とすると、S = k ln W。

はじめは全部が左（W = 1, S = 0）。いちばん場合の数が多いのは n ≈ N/2 で、ln C(N, N/2) ≈ N ln 2。これは熱力学で求めた自由膨張のエントロピー変化 ΔS = Nk ln(V₂/V₁) = Nk ln 2 と一致する（N が大きいほどよく合う）。

全部が左に戻る確率は (1/2)N。N = 200 なら 10−60 程度で、宇宙の年齢のあいだ待っても起こらない。

速度を反転しても戻らないのは？

理想的な（誤差のない）弾性衝突の力学なら、どれだけ待ってからでも全粒子の速度をぴったり逆にすれば、粒子は来た道を逆にたどって必ず元に戻ります。力学そのものは時間を逆にしても成り立つので、待つこと自体が可逆性を失わせるわけではありません。

このシミュレーションで、しばらく待ってから反転すると戻らないのは、時間を細かく区切って計算するときの誤差と数値の丸め誤差のせいです。その小さな誤差が衝突のたびに大きくなり（カオス）、やがて完全にずれてしまいます。現実の気体でも、すべての粒子の速度を寸分たがわず逆にすることはできず、わずかなずれがすぐに増幅されます。「元に戻る」のは、場合の数でいえばとても特別な、ほとんどありえない状態です。

熱の移動のエントロピー（2次元理想気体）

体積一定なら dS = dQ/T、CV = Nk なので S = Nk ln T + 定数。左右の気体と仕切り壁（熱容量 Cw）の和 S = N₁ ln T₁ + N₂ ln T₂ + Cw ln Tw を表示しています。粒子数が有限なので温度はゆらぎ、S も小さくゆらぎます。
