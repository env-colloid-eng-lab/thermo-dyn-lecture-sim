ねらい

空気の塊を少し持ち上げると、周りの圧力が下がるので 断熱膨張 して冷える（03 の断熱膨張と同じ）。冷え方は乾燥断熱減率 Γd = g/cp ≈ 9.8 K/km。周囲の気温がそれよりゆっくり下がっていれば、持ち上げた空気塊は周囲より冷たく重いので戻される（安定）。周囲が速く下がっていれば、空気塊は周囲より暖かく軽いので昇り続ける（不安定 → 対流）。

空気塊は断熱的に動くので、温位 θ（つまりエントロピー）を保つ。上ほど温位が高い（エントロピーが大きい）大気は安定、上ほど低ければ不安定。温度ではなくエントロピーで比べると、どちらへ動くかが分かる。

やってみよう

  1. Γenv = 6.5 K/km（平均的な対流圏）で「持ち上げて離す」。空気塊は上下に振動する。周期は？
  2. Γenv を 9.8 K/km より大きくする。持ち上げた空気塊はどうなる？ 温位の図では、上ほど θ が低くなっている。
  3. Γenv を負にする（上空ほど暖かい：逆転層）。振動は速くなる？ 冬の朝に煙や霧が地表付近にたまるのはなぜ？
  4. Γenv = Γd ちょうど（θ が一様）にすると？
  5. 下の圧力の図で、等温大気（11 の沈降平衡と同じ指数関数）と乾燥断熱の大気を比べる。地表の圧力が同じでも、上空の圧力は違う。
問い　1000 hPa、300 K の空気塊を 800 hPa まで断熱的に持ち上げると何 K になる？ そのときの温位は？（Rd/cp = 0.286）
問い　地上で 300 K の空気塊を 1 km 持ち上げる。周囲の減率が 6.0 K/km なら、空気塊は周囲より暖かい？冷たい？ どちらへ浮力が働く？
問い　周囲の大気が「乾燥断熱減率で下がっている」のは、どのような状態だろう？ 対流がよく混ぜた大気で、温位（エントロピー）がどうなっているかを考えよう。
式のまとめ（乾燥空気）

単位質量あたりの第一法則と静水圧平衡 dP/dz = −ρg から、周囲と同じ圧力を保ちながら断熱的に動く空気塊は cp dT = v dP、つまり dT/dz = −g/cp = −Γd（周囲との密度差が小さい近似）。

空気塊を周囲と同じ温度の高さ z₀ から ξ だけ動かすと、温度差は (Γenv − Γd)ξ、浮力による加速度は g(Tparcel − Tenv)/Tenv。まとめると d²ξ/dt² = −N²ξ、N² = (g/T)(Γd − Γenv)。N² > 0 なら周期 2π/N の振動（数分〜十数分）、N² < 0 なら指数関数的に離れていく。このページでは摩擦や周囲との混合を無視しています。

温位の高さ変化は (1/θ)dθ/dz = (Γd − Γenv)/T なので、N² と同じ符号。乾燥空気のエントロピーは s = cp ln θ + 定数。

周囲の圧力は、静水圧平衡と状態方程式から求めています。等温なら P = Ps e−gz/(RdT)（分子の沈降平衡と同じボルツマン因子）、一定の減率 Γ なら P = Ps(T/Ts)g/(RdΓ)。
