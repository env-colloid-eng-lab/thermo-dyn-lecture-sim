ねらい

受容体 R とリガンド L の結合 R + L ⇄ RL は、11 の二状態モデルと同じく「エネルギーが低い（結合する）」と「広い場所を動き回れる（離れている）」の競争です。平衡で結合した割合は f = c/(Kd + c)（教科書 4.8 節の式 (4.13)）。c は自由なリガンドの濃度、Kd は解離定数で、ちょうど半分の受容体がふさがる濃度です。

受容体は1つに1個までしかつかないので、濃度を上げても f は 1 を超えず、飽和します。

やってみよう

  1. 再生して、結合した割合 f が理論（破線）のまわりに落ち着くのを見る。結合も解離も続いているが、つく数と離れる数がつり合っている。
  2. リガンドの数を変えて「はじめから」→ 落ち着いたら「いまの値を記録」。何点か記録すると、点は f = c/(Kd + c) の曲線に乗る？　c = Kd で f = 1/2 になる？
  3. リガンドをとても多くする。f は 1 に近づくが超えない（飽和）。
  4. ε を大きくする（結合が強い）と Kd は小さくなり、薄い濃度でもよく結合する。ε を 1 下げると Kd は何倍？
  5. 温度 T を上げると、結合していたリガンドが離れていく。エネルギーで得する結合より、自由に動ける（エントロピーの大きい）状態の方が有利になる。
問い　受容体とリガンドを同じ数ずつ入れたとき、「入れたリガンドの数」から求めた濃度を c に入れて f を計算すると、測定よりも大きくなる。なぜ？（教科書の途中の問い 4.4）
問い　Kd ∝ e−ε/kT。結合のエネルギーが 1 kT 増えると、半分が結合する濃度は何分の1になる？　薬が「よく効く（低い濃度で働く）」とはどういうことか？
問い　11 の「二状態」（広さの違う二領域）と見比べよう。結合部位の面積 πa² は二状態モデルの何に当たる？　温度を上げると結合が外れるのは、タンパク質の変性と同じしくみ？
平衡の式の導き方

定温・定面積で、自由なリガンドの化学ポテンシャルは μL = kT ln(c λ²)（λ は温度で決まる長さ）。受容体にとらえられたリガンドは、面積 πa² の中でエネルギーが ε 低いので、1つの部位あたり f/(1 − f) = c · πa² · eε/kT で平衡になる（結合の自由エネルギー変化 = 0）。これを書き直すと f = c/(Kd + c)、Kd = e−ε/kT/(πa²)。

1 mol あたりで書けば Kd = c° eΔrG°/RT（教科書の式）。ΔrG° = ΔrH° − TΔrS° のうち、−ε がエネルギー（エンタルピー）の部分、πa² が「狭いところに閉じ込められる」エントロピーの部分に当たる。

入れた量と自由な量（全量の保存）

リガンドを NL 個、受容体を M 個入れ、そのうち n 個が結合したとすると、自由なリガンドの濃度は c = (NL − n)/A（A：容器の面積）。平衡の式 n/(M − n) = c/Kd と連立すると n の2次方程式になる。下の「全量から求めた理論」はこれを解いた値。結合で自由なリガンドが減るので、入れた量で計算すると結合を多く見積もってしまう。

このモデルについて

2次元剛体円板気体（m = 1、k = 1）。受容体は動かない点で、リガンドの中心が半径 a = 1 以内に入ると結合する（1つの部位に1個まで）。結合したリガンドは部位にとどまり、離れる速さは koff = kon e−ε/kT/(πa²)（kon = a√(2πkT/m) は気体分子運動論から決まる、つく速さ）で、離れるときは環境の温度の速さで飛び出す。この速さの組み合わせで、平衡の割合が熱力学の式と一致する。帳簿は1回ごとのエネルギー変化をすべて足したもので、ΔU = Q + W が厳密に成り立つ。
