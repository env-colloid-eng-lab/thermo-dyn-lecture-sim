Experiment
A: Insert walls to divide into subsystems

Moving a partition re-inserts it at the new position (the reference is "the whole before partitioning"). Which particles end up on which side at the moment of insertion is a matter of chance, so the ratio of N is off by a few percent (a fluctuation due to the small number of particles). With adiabatic partitions, the T of each subsystem also stays fixed at whatever chance value it had at that moment.

B: Prepare another system in the same state and join them

① places a copy in exactly the same state as the original system (N, V, U) on the right; ② makes them one system.

Goal

Check the definitions from the lecture with numbers.

  • Additivity: state variable of the combined state = sum of the state variables X(A ⊕ B) = X(A) + X(B)
  • Extensivity: state variable of the state scaled by λ = λ times the state variable X(λA) = λ X(A)
  • Intensivity: unchanged when scaled by λ Y(λA) = Y(A)

Try it

  1. A: Insert the vertical partition. What do you get when you add N, V, U of subsystems 1 and 2? And when you add T, P?
  2. Set the partition position to 25 (subsystem 1 is 1/4 of the whole). In the row "Subsystem 1 ÷ whole", what are the ratios of N, V, U? Of T, P?
  3. Insert both vertical and horizontal partitions to make four subsystems (Figure A in the slides).
  4. B: Place an identical system next to it and remove the partition. N, V, U double. What about T, P?
